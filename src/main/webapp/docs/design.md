Design system for "HUST Cine", a Vietnamese movie ticket booking website.

Brand identity: inspired by the spirit of a technical university in Hanoi: disciplined, bold, youthful, trustworthy. LIGHT theme by default: clean white backgrounds with a strong red accent. Do NOT use any real university logo or emblem; create an original simple wordmark "HUST Cine" with a small geometric mark (abstract film-reel combined with a gear or grid motif).
Header shows a live clock chip on desktop (e.g. "Thứ Tư, 21/10/2026 · 14:32") in a subtle pill next to the cinema selector; on mobile it moves into the top of the showtime picker.

Colors:
- Background #FFFFFF, alt surface #F7F4F4 (warm off-white), borders #E8E0E0
- Primary red [#C8102E] for buttons, active states, selected seats, links
- Deep red #8E0B1F for hero bands, footer, ticket headers
- Red tint #FDECEF for hover and selected backgrounds
- Ink #1A1A1F for text, secondary text #5B5B66, muted #8A8A94
- Gold #B8902A only for VIP, Luxury and rating stars
- Semantic: success #1E8E5A, warning #D98A00, error #B3261E, info #1F6FD1
Text contrast must meet WCAG AA. Use red sparingly so that it stays powerful: large white space, red for the single main action on each screen.

Typography: [Be Vietnam Pro] (Vietnamese diacritics must render correctly), bold geometric headings, comfortable body text.
Shape and detail: 4px spacing grid, 12px card radius, 8px button radius, thin 1px lines, subtle engineering-grid pattern on deep red bands, soft shadows. Hero imagery uses full-bleed backdrop with a deep-red gradient overlay to keep a cinematic feel on a white site.

Seat-state styling (must be distinguishable without color alone): available = white with gray outline; selected = solid red with check icon; sold = light gray with diagonal hatch; held by another user = amber with clock icon; VIP = gold outline with crown icon; couple seat = double-width; recliner (luxury) = rounded large seat with footrest icon; wheelchair = blue icon.

Shared components: sticky header (logo, search, cinema selector, VI/EN switch, login or avatar), movie poster card (2:3 poster, age badge P/K/T13/T16/T18, format badge 2D/3D/IMAX, room-type badge, rating), buttons (primary red, secondary outline, ghost, destructive, loading), inputs, tabs, modal, toast, stepper, skeleton, empty and error states, footer in deep red.

All UI copy in natural Vietnamese. Realistic Vietnamese movie titles, placeholder cinema names (e.g. "HUST Cine Đại Cồ Việt", "HUST Cine Times City", "HUST Cine Cầu Giấy"), prices in VND (95.000đ). No lorem ipsum, no real brand logos or real film posters.

Also SOLD_OUT (gray, "Hết vé") and CANCELLED (strikethrough, "Đã huỷ"). Past showtimes of today are collapsed under a "Xem suất đã qua" toggle. S6. CHECKOUT: Step 3. S9. CINEMAS: Cinema list with map, filters by city, cinema detail page with amenities, rooms, today's showtimes. Also FAQ, contact, 404 page
